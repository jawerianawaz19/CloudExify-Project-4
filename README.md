To-Do List Manager

A simple Python command-line To-Do List Manager that helps users create and manage tasks.

Features
Add tasks with title, priority, category, and due date
View all or pending tasks
View high-priority tasks
Mark tasks as completed
Edit tasks
Delete tasks
Search tasks by keyword
View statistics
Check overdue and today's tasks
Automatically saves tasks in tasks.json
Requirements
Python 3.x
No external libraries required
How to Run

Save the program as todo.py and run:

python todo.py


The program will automatically create and use tasks.json to store your tasks.

Task Information

Each task contains:

ID
Title
Priority: High, Medium, or Low
Category: Work, Study, or Personal
Due date
Status
Creation date
Menu
1. Add task
2. View all tasks
3. View pending tasks
4. View high priority
5. Mark task as done
6. Delete task
7. Show statistics
8. Show overdue tasks
9. Show tasks due today
10. Search tasks
11. Edit task
12. Exit

Purpose

This project demonstrates basic Python concepts such as functions, lists, dictionaries, JSON file handling, loops, input validation, and date/time operations.
